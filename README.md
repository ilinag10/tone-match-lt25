# Fender Mustang LT25 Tone Matcher

An end-to-end DSP and Machine Learning pipeline that infers target **Fender Mustang LT25** amplifier presets and FX settings directly from YouTube guitar audio. 

* **Stem Separation:** Isolates clean guitar tracks from mixed YouTube audio using Demucs models (`htdemucs` / `htdemucs_6s`).
* **Audio Analytics:** Extracts spectral metrics (spectral centroid, flatness, crest factor, active RMS) and 13 Mel-Frequency Cepstral Coefficients (MFCCs).
* **Normalized $k$-NN Engine:** Scales audio features via `StandardScaler` and queries target vectors using Euclidean distance metrics.
* **Fender LT25 Mapping:** Reconstructs exact amplifier models, 5-band EQ settings (Gain, Treble, Middle, Bass, Volume), and active FX slots (Stomp, Mod, Delay, Reverb).
* **Benchmarking & Automated Cleanup:** Includes offline evaluation utilities and automatic workspace cleanup (`shutil.rmtree`) for intermediate audio files.

## Installation & Setup
1. Prerequisites
   - Python: 3.9 - 3.11 recommended
   - FFmpeg: Required by `librosa` and `demucs` for audio decoding. Ensure FFmpeg is installed and added to your system PATH.
     * Windows (Chocolatey): `choco install ffmpeg`
     * Mac (Homebrew): `brew install ffmpeg`
     * Linux (apt): `sudo apt install ffmpeg`

2. Environment Setup
```bash
# Clone the repository
git clone https://github.com/ilinag10/tone-match-lt25.git
cd tone-match-lt25

# Create virtual environment
python -m venv venv

# Activate virtual environment
# On Windows:
venv\Scripts\activate
# On macOS/Linux:
source venv/bin/activate

# Upgrade pip and install dependencies
pip install --upgrade pip
pip install -r requirements.txt
```

3. Build & Train Models
   Before running inference, build the feature anchors and train the $k$-NN index:
```bash
  # Step A: Extract DSP features from anchor audio library
  python scripts/extract_anchor_features.py
  
  # Step B: Train scaler and fit k-NN index (saves to models/)
  python scripts/prepare_data.py
```

## Usage
### Run Main Inference Pipeline
Downloads YouTube audio, separates the guitar stem, extracts DSP features, and outputs the target Fender LT25 recipe:
```bash
python main.py
```
### Run Streamlit Web App
Launch the interactive web interface:

```bash
streamlit run app.py
```
### Run Multi-Config Benchmark
Runs download and stem separation once, then compares matching results across $k=1, 3, 5$:

```bash
python scripts/benchmark_matches.py
```

## Distance Metric Guide
Euclidean distance is evaluated in standard deviation space:
- $< 1.0$: High tonal correlation. Almost identical EQ and harmonic spectrum.
- $1.0 - 2.5$: Moderate match. Accurate core gain structure and amp voicing.
- $> 3.5$: Low correlation. Input audio lies outside current anchor preset bounds
